# 美術素材來源

經原公司同意（依倉庫擁有者說明），可參考或直接使用原作的美術、音樂等素材，目標是盡量貼近原作。使用原作素材時需在 docs/美術素材來源.md 記錄來源。若無原始檔案，可依 reference/ 的截圖與影片重繪貼近原版的素材。

以下是目前仍在遊戲裡的生成圖紀錄。這些點陣美術（武將立繪、頭像、主城建築、各畫面背景）是 **2026-11-04 以 Grok Bot 內建的 GenerateImage 圖像生成工具產生**的。
沒有圖檔時，遊戲自動回退為以程式繪製的向量（SVG）美術。之後若改用原作素材或依 reference/ 重繪，在本文件補上來源。

## 處理流程

1. GenerateImage 產生 JPG（角色在純色洋紅 #FF00FF 或亮綠 #00FF00 背景上，便於去背）→ 原檔存於 `src/assets/raw/`（角色、建築）與 `src/assets/bgraw/`（背景）。
2. `tools/art_process.py`：色鍵去背、裁出角色外框 → 全身立繪（高 360px，WebP q72）＋ 頭部頭像 128×128（WebP q80）；建築寬 380px（通天塔 220px）。
3. `tools/bg_process.py`：背景縮到寬 1280px（非寬幅 1024px），WebP q66。
4. `tools/build-assets.js`：把 `src/assets/out/*.webp` 以 base64 寫進 `src/js/assets.generated.js`（`MJ.ASSETS`），由 `tools/build.js` 內嵌到單一 HTML。
5. 執行時 `MJ.Art.url()` 把 data URI 轉為 blob URL（只轉一次），`<img decoding="async" loading="lazy">` 顯示；不支援 WebP 的瀏覽器回退 SVG。
