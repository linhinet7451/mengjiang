# 《猛將無雙》實戰影片分析

來源影片：<https://m.youtube.com/watch?v=RlsGxFnwKZk&pp=ygUM54yb5bCH54Sh6ZuZ>

分析結果已依影片分析工具整理於本文件。本文件只記錄能由影片辨識、且適合離線單檔版本的項目；影片解析度與 Flash 幀率有限，細小圖示與原始素材名稱不作臆測。

## 影片中可辨識的原版戰鬥元素

- 左右敵我棋盤站位，單位腳下有圓形法陣／選中光環。
- 頂部有雙方總生命條、數值，以及中央的對陣／回合提示。
- 出手時背景壓暗，紅色格子代表受擊範圍，綠色格子代表施放者。
- 普攻帶有近戰突進或遠程投射；技能名稱以大型金／紅字短暫顯示。
- 無雙包含暗場、角色立繪 cut-in、技能名稱、攻擊範圍小棋盤與總傷害提示。
- 普通傷害、暴擊、治療、閃避／狀態都有不同顏色的飄字；暴擊字較大並伴隨震動。
- 底部有我方頭像與生命／無雙條，右下可見速度與跳過等戰鬥控制。
- 勝敗後進入獨立結算畫面；影片中的細節不足以安全重建原始素材，因此沿用目前可讀性較高的離線結算面板。

## 與目前 repo 的核對

目前版本已具備：大棋盤與陣法格、我方頭像列、雙方總生命條與數值、回合文字、紅／綠攻擊範圍、近戰突進／遠程光球、技能名稱、無雙高解析 cut-in、直書金色技名、暴擊／治療／閃避飄字、速度／跳過／戰報／陣法控制、勝敗結算與原生音效切換。因此影片中大部分高辨識度元素已經落地，無需重複加入大型圖片。

本輪新增的低成本視覺補強是：角色行動時，腳下法陣的內圈會以旋轉虛線高亮，對應影片中「選中／行動角色腳下出現旋轉光環」的辨識效果。它使用 CSS 動畫，不增加素材體積，也不改變戰鬥結果。

## 後續素材優先級

1. **高優先：** 若能取得合法且清晰的原版技能名稱圖、屬性背景／雪夜背景、狀態 icon，可替換目前 CSS 文字與粒子效果；不可用未確認身份的角色 cutout 代替。
2. **中優先：** 取得更清晰的結算畫面與底部控制列截圖後，再精修旗幟／對陣圖示與按鈕外觀。
3. **低優先：** 角色 idle／attack sprite sheet、女性技能語音、完整原版 BGM。現有單檔上限與音訊授權限制下，先維持目前 CSS／Web Audio 方案。

透明角色包中的 `t_006`、`t_011`、`t_036`、`t_078` 雖有標註版參考圖，但尚未能與 runtime 武將 ID 建立全數可靠對應，故本輪不替換 `h_*.webp`，避免角色錯配。
