# 《猛將無雙》HTML5 重製：資料考證

本文件列出遊戲中**每一類**數值與設定的來源，以及可信度等級。逐筆的武將、陣法、關卡資料表放在《附錄-資料表.md》，由 `node tools/gen-appendix.js` 從遊戲實際讀取的 JSON 自動產生，所以和程式不會對不上。

## 0. 等級定義

| 等級 | 意義 |
|---|---|
| **A** | 原作截圖或影片中**親眼可見**的畫面、文字、數字，或官方資料 |
| **B** | 可靠的玩家攻略，例如巴哈姆特哈啦板〈猛將無雙 入門指南〉，以及騰牛網、聚俠網的攻略 |
| **C** | 由 A/B 合理推論。例如由截圖數字反推公式，或某技能歸屬於哪位武將 |
| **D** | 本作自行設計。原作有此機制但數值未知，或原作根本沒有 |

原則：

- 只要有 C 或 D 的成分就照實標註，不把推測寫成官方數值。
- 一筆資料可能混合等級，例如「A(登場) C(數值)」表示武將確實出現在原作，但能力值是推估的。

## 3. 傷害類型

- **A（影片3讀取畫面提示）**：原作有**物理、法術、絕技**三種傷害。
- **第二階段起三種都有**：力系（力耐、力敏）＝物理，對物防；智系＝法術，對法防；敏系（敏耐等）＝**絕技**，以「絕技攻」對「絕技防」。
  - 絕技攻＝敏捷 ×5＋5（敏系）或 敏捷 ×2＋3（其他）；絕技防＝敏捷 ×0.5＋耐力 ×0.4（**D**，原作機制不明，仍列待考證）。
  - 由類型決定傷害種類是本作推論（C）；原作畫面只確認有三種傷害名稱。
- 傷害公式是**暫定（D）**：

  ```
  傷害 ＝（攻擊 × 技能倍率 ＋ 固定值）×（0.95～1.05）− 對應防禦
  ```

  - 至少造成 1 點傷害。
  - 暴擊率 5%＋暴擊值，暴擊傷害 ×1.5。
  - 命中率 90%＋命中−閃避，限制在 20%～100%。
- 戰鬥中可按「公式」查看這些規則。
