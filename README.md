# 猛將無雙 HTML5 單機重製（正式版：第五階段＋奇遇）
https://linhinet7451.github.io/mengjiang/
這是向 Facebook 社群遊戲《猛將無雙》致敬的**非官方、單機、離線** HTML5 重製。

- 目前遊戲內的點陣圖多為先前生成的版本（其中韋小寶、貂蟬、呂布、東方不敗、王語嫣、鰲拜、典韋、梅超風、袁紹、阿珂 10 名武將已依原版截圖重繪）：97 張 Q 版角色立繪與頭像、9 棟主城建築、16 張背景（WebP 內嵌，提示詞見 docs/美術素材來源.md）；缺圖時回退程式繪製的 SVG。經原公司同意（依倉庫擁有者說明），可參考或直接使用原作的美術、音樂等素材，目標是盡量貼近原作。使用原作素材時需在 docs/美術素材來源.md 記錄來源。若無原始檔案，可依 reference/ 的截圖與影片重繪貼近原版的素材。
- 數值依可信度標成 A／B／C／D 四級，詳見 `docs/資料考證.md`。
- **除了 A 級項目，其他數值都不是原作數值。**

## 怎麼開始玩

1. 用瀏覽器直接開 `dist/mengjiang.html`。這是單一檔案，可以離線使用，不需要伺服器或網路。
   - 已測試：Chromium、WebKit（模擬 iPhone 13）。
2. 想先檢查環境，可以開 `dist/boot-test.html`。它會自我檢測 JSON、LocalStorage、SVG、各模組、資料數量，並模擬一場戰鬥。
3. 手機直拿時，畫面會自動旋轉成橫向，不會出現水平捲軸。

## 遊戲玩法

1. **建立角色**：輸入俠名，選性別與主角類型（力耐、力敏、敏耐）。開局會送兩名武將。
2. **主城**：
   - 左上角顯示頭像、等級、經驗、精力；上方是金幣、銀幣與禮包。
   - 點浮空島上的建築進入功能，包括生死劫九層挑戰。
   - 底部列：道具、陣法、日誌、郵件、商城、設置。商城新增商品類別與付款貨幣交叉篩選。
3. **聚賢莊**：
   - 有普通、白金、紫金、至尊四種刷新。各有冷卻時間，可以花金幣加速。
   - 刷出武將後按「拜訪」付銀幣招募，可在「查看品質機率」看機率表。
   - 「我的武將」可以解僱武將換將魂（黑色武將不給將魂）；「將魂召喚」用將魂召喚武將。
4. **神武殿**：
   - 「裝備」分頁：6 格（武器、頭盔、盔甲、披風、腰帶、飾品），按「最強」自動換上最好的裝備。
   - 「技能」分頁：主動、無雙、被動三欄，用技能書升級（1～9 級），9 級再用神技書突破成「·神」。技能等級不能超過武將等級。
   - 「培養」分頁：用培養丹隨機調整四維加成，結果可保留或放棄；上限隨等級提高。
   - 「心法」分頁：用心法秘笈修練（20、40 級各多開 1 欄），用心法殘頁升級，遺忘會退回秘笈。
   - 「升階」分頁：用該武將的將魂升星（最多 5 階），每階四維 +6%。
   - 「訓練」分頁可讓一名武將掛機獲得經驗。
   - 傷害分三種：力系＝物理（對物防）、智系＝法術（對法防）、敏系＝絕技（對絕技防）。
4b. **神兵坊**（5 級開放）：強化（上限＝神兵坊等級，+5 以下必成功，失敗不掉級）、洗煉（附加屬性，可保留或放棄）、鑲嵌（依品質 1/1/2/3 孔，同類寶石限 1 顆；摘除符可保留寶石）、寶石合成（4 合 1，最高 6 級）。
4c. **將星錄**（主角 30 級開放）：顯示原版攻略記載的 19 組將星組合，並可消耗同名將魂提升武將將星等級（各品階依來源表，最高記載 Lv18；來源缺值不可升級）。只有兩組來源完整的條件會顯示進度，其餘缺值明示未知。所有組合效果（包括原文列出的數字）目前只顯示來源文字，尚未套入戰鬥屬性。舊版二十八宿星盤投入會在存檔遷移時折回星魂餘額；已在舊 16 級門檻下解鎖者保留入口。內含**武將圖鑑**：每收錄一名武將，全隊四維戰鬥屬性 +0.2%（上限 15%）。
   - 武將可以出戰或休息。
5. **陣法**：在底部列開啟，選擇陣型（方圓、魚鱗……），把武將放到格子上。可上陣人數隨主角等級增加：Lv1 3 人，15/25/35/45/55/65 級各 +1，最多 9 人（9 人時九宮格全開）。陣法加成會實際套用到全隊。
6. **虛空之門**：
   - 共 8 章 72 關（分兩卷），關卡分普通、精英、王、隱藏。挑戰會消耗精力。
   - 勝利可以拿到經驗、銀幣、裝備、將魂，並解鎖下一關。
   - 全圖三星後開啟隱藏關。
7. **戰鬥**：
   - 全自動進行，有 1x／2x 速度與跳過，可以查看戰報與公式。
   - 上方是雙方總血條。暴擊以黃色大字顯示，無雙技有切入畫面並顯示總傷害。
   - 戰敗時畫面轉灰，並給出如何提升戰鬥力的建議。
   - 主角 30 級前戰敗不扣精力。
   - P3.6：現有精英／BOSS 首領以銀／金框辨識；RV15 戰報可顯示來源支持的炸彈、旗幟、噴火槍格形事件。因本作沒有榮譽試煉模式，事件須由戰鬥呼叫明確傳入；效果只依來源已知內容預覽，不擅自套傷害或道具經濟。
8. **精力**：隨時間回復（速度依經濟模式），升級時精力回滿。也可以用精力湯或大補丸回復。
9. **通天塔**（22 級開放）：共 100 層，每 5 層精英、每 10 層首領。不耗精力、戰敗無損失；每層只有**首次登頂**給獎勵（銀幣、培養丹／技能書、寶石、心法、星魂、全隊經驗）。依最高層數每天可領一次「每日塔俸」。
10. **無極幻境**（12 級開放）：三欄挑戰面板——初窺之境（12 級，3 波）、登堂之境（25 級，5 波）、化境（42 級，7 波），各每天 2 次。多波連戰，**存活武將的生命與怒氣延續到下一波**，陣亡者不再出場。每過一波得銀幣與經驗，全破得寶箱，首次全破另有獎勵。戰鬥中可按「下一波」逐波觀看，或「略過，看結算」。
11. **農田**：3×3 田地，農田等級決定開墾塊數（Lv1 3 塊，每 3 級多 1 塊，最多 9 塊）。四種種子（搖錢樹 4 小時→銀幣、悟道竹 6 小時→主角經驗、靈石花 8 小時→寶石、英魂草 12 小時→隨機將魂）。**依真實時間成長，關閉遊戲也會繼續長**；化肥可讓剩餘時間減半（每次種植限一次）；「一鍵收成」。
12. **任務**（左側「任務」按鈕）：每日（7 項＋活躍度 30/60/90 寶箱，午夜重置）、主線、成就（10 種，分階）、簽到（月曆，補簽 10 金，累計 7/14/21/28 天獎勵）。可一鍵領取所有已達成的主線、歷練任務、活躍寶箱與成就；簽到及簽到累計獎勵仍使用原按鈕。
13. **經濟模式**（設置）：「標準」或「單機加速」（精力每 1 分鐘、農田 4 倍速、訓練 2 倍、戰鬥銀幣與塔俸 ×1.5）。
14. **拜訪武將**（8 級開放，單機 AI 競技場）：挑戰 30 支 AI 名將隊伍爭排名，每天 5 次，勝利換位並得獎勵，可重播最近 6 場戰報。
15. **越戰越勇**（防卡關）：同一關每連敗一次，下次挑戰我方生命與攻擊 +8%（最多 +80%），通關後歸零。關卡面板與戰敗畫面會顯示目前加成。
16. **奇遇**（主角 5 級開放，主城上方「奇遇」按鈕）：
   - **華容道**：六個布局（12～116 步），點棋子再按方向鍵或旁邊空格移一格，可悔一步、重來；曹操從下方出口脫身即破解。每個布局首次破解有獎勵，每天第一次破解另得銀幣與精力湯，依步數評一到三星。
   - **觀星台**：點北斗七星占卜今日星運（大吉～末吉，全是正面效果），得銀幣與道具，並讓當天虛空之門勝利時全隊多拿 3～20% 經驗。每天第一次免費，之後 10 金，最多 3 次。
   - **玄機盤**：12 格轉盤，機率表公開；每天第一次免費，之後花銀幣；10 次保底必中「玄機大獎」。
17. **聲音與特效**：音樂、音效全為 WebAudio 即時合成的原創曲（各場景不同）。主城右上角喇叭一鍵靜音；設置可分開開關音樂／音效，並選「戰鬥特效：自動／完整／省電」（省電關閉光環動畫、火花、閃光與大震動，適合舊手機）。
18. **生死劫**：九層首領依序挑戰，首通可得銀幣與全隊經驗；九層名稱依 G2(88)，等級、解鎖方式與獎勵皆為 D 級本作設計。

## 存檔

- 每次操作後自動存到 LocalStorage（`mjws_save`），並保留一份備份（`mjws_save_backup`）。主存檔損毀時會自動改讀備份。
- 「設置」裡可以：
  - 立即存檔。
  - 匯出存檔：產生文字，可以複製。
  - 匯入存檔：會檢查格式與版本；升級步驟失敗時保留舊版本並拒絕匯入，不會把部分轉換的存檔假標為新版。
  - 刪除存檔重來。
- 遇到未預期的錯誤時會顯示錯誤畫面，提供「重新開始」「顯示存檔文字（備份用）」「刪除存檔重來」三個按鈕，不會只留下白畫面。

## 開發者：建置與測試

需要 Node.js。測試另外需要 Playwright，以及 Chromium 和 WebKit 瀏覽器。

```bash
npm install                                   # acorn、playwright、terser
node tools/gen-data.js && node tools/web2-data.js P1 P2 P3 P4 && node tools/build-data.js   # 基礎資料＋可重跑來源補丁＋runtime bundle

node tools/es5check.js                        # 確認所有 JS 都是 ES5
node tools/gen-appendix.js                    # 產生 docs/附錄-資料表.md
sh tools/runtests.sh                          # 完整單元測試（含 P3-3～P3-6、P4 專項）
node tests/e2e.js all                         # 端對端測試：chromium | webkit-iphone | chromium-phone | all
node tools/showcase.js                        # 宣傳截圖：無雙特寫、AOE 總傷害、首領戰
```
